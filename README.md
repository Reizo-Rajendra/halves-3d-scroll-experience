# HALVES — 3D Scroll Animation Experience 🍉🍋

An award-winning 3D scroll-driven product experience built with **Three.js**, **GSAP ScrollTrigger**, and **Lenis** smooth scroll. Featuring procedural photorealistic fruit models, dynamic studio lighting, physical can slicing with local clipping planes, and an official **zears Gaming** showcase.

Inspired by creative 3D web trends and video showcase.

---

## ✨ Features

- **Photorealistic 3D Models**:
  - Realistic 330ml beverage can with brushed aluminum lid, physical water condensation droplets, and uncropped nutrition label.
  - Sliced lime wheels with over 2,200 translucent juice vesicles, delicate carpel membranes, and waxy rind bump maps.
  - Watermelon wedges with organic crystalline sugar cell reflections, soft pith gradient, and 3D teardrop seeds.
  - 3-lime whole fruit pyramid with waxy skin pores, stem buttons, and leaves.
- **Can Slicing Animation**:
  - Local clipping planes separating the can into 3 distinct bands (46% watermelon juice, 46% spring water, 8% lime juice & zest).
  - Dynamic SVG elbow connector lines tracking 3D world points to 2D screen space.
- **Dynamic Color Atmosphere**:
  - Warm luxury studio cyclorama at the start (no pale or washed-out white).
  - Deep emerald green atmosphere with orbiting fruit slices and revolving typography ribbon.
  - Saturated ruby watermelon red section with floating refractive ice cubes and calorie counter.
- **Creator Showcase**:
  - Official [zears Gaming YouTube](https://www.youtube.com/@ZEARS_GAMINg) luxury obsidian glass card with channel statistics and subscribe action.
- **Mobile Responsive**:
  - Adaptive Three.js camera distance and FOV scaling for smartphones and tablets.
  - 60 FPS silky-smooth scroll physics with Lenis.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/Reizo-Rajendra/halves-3d-scroll-experience.git
cd halves-3d-scroll-experience
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
